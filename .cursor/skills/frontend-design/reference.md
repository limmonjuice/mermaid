# Frontend Design – Reference

## Aesthetic Directions (Extended)

- **Brutalist**: Raw, bold type (e.g. Space Mono, Bebas), high contrast, visible structure, little decoration.
- **Maximalist**: Dense layout, patterns, rich color, decorative elements, layered visuals.
- **Retro-futuristic**: CRT/terminal feel, neon accents, scanlines, tech nostalgia, monospace or display fonts.
- **Luxury**: Serif headlines, generous whitespace, muted or gold/cream accents, refined spacing.
- **Playful**: Rounded shapes, bright palette, friendly micro-interactions, soft shadows.
- **Editorial**: Magazine-style hierarchy, strong headlines, asymmetric grid, pull quotes, clear sections.
- **Dark / terminal**: Dark bg, monospace or technical font, single accent (e.g. green, cyan), code-like feel.
- **Neo-brutalist**: Black borders, flat color blocks, raw type, no soft shadows.

## Anti-Patterns to Avoid

- Single purple/violet gradient as hero background
- Inter or Roboto as the only font
- All cards same border-radius (e.g. 8px everywhere)
- One accent color (e.g. one blue) for all CTAs and links
- Centered single-column layout with no hierarchy
- Decorative animations that don’t support the narrative
- Placeholder lorem ipsum in final code when real copy could be suggested

## Typography Pairing Examples

- Display + monospace: e.g. Clash Display + JetBrains Mono
- Serif + sans: e.g. Fraunces + DM Sans
- Editorial: e.g. Playfair Display + Source Sans 3
- Brutalist: e.g. Space Mono, Bebas Neue, or Archivo Black

## Context-Aware Details

- **Dashboard**: Clear data hierarchy, scannable metrics, consistent chart/table styling.
- **Landing**: Strong headline, one clear CTA, social proof or feature blocks that match the aesthetic.
- **Settings panel**: Grouped sections, toggles/inputs that fit the theme, clear labels.
- **Dark mode**: Ensure contrast (WCAG), avoid pure black unless intentional; use dark gray + accent.
